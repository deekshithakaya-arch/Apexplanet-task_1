# Apexplanet-task_1
Task 1 - Data Immersion and Wrangling using the Superstore dataset. Performed data cleaning, preprocessing, handling missing values, and data quality improvements using Python.

##Task Description
Performed data immersion, data cleaning, and data wrangling on a dataset using Python. The project involved data profiling, handling missing values, checking duplicates, standardizing column names, validating data types, outlier detection, feature engineering, creating a data dictionary, generating sample insights, and saving the cleaned dataset.

- Pandas
- NumPy
